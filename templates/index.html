Supported inputs & how PCAP conversion works

CSV — must contain the 80 numeric features generated by CICFlowMeter (e.g. Flow Duration, Total Fwd Packets, Flow Bytes/s, SYN Flag Count). An optional Label column (BENIGN / DDoS) enables evaluation metrics.

PCAP / PCAPNG — captured with Wireshark, tcpdump, or any standard tool. On upload, our built-in flow extractor parses the capture, computes the 80 CIC-DDoS2019 features in pure Python (no Java, no external tools), and feeds them straight into the analysis.
